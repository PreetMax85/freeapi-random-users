# FreeAPI Random Users

A React-based user directory built with Vite and Tailwind CSS.

## Features

- User card grid with avatar, name, email, phone & location
- Search by name or email (client-side)
- Gender & nationality badges
- Load more pagination
- Skeleton loading cards & error handling

## Tech Stack

- React (Vite)
- Tailwind CSS
- FreeAPI Random Users endpoint

## API Endpoint Used

```
GET https://api.freeapi.app/api/v1/public/randomusers
```
